# Hook & Row

Acompanhamento de receitas de crochê, em português, num único arquivo HTML, sem servidor.

- Cole a receita escrita ou abra um PDF; cada carreira ou volta vira uma etapa com contador de pontos e de repetições.
- Comandos de voz em português com palavra de ativação ("Novelo, acabei de fazer o terceiro aumento").
- O progresso fica salvo no navegador. Use **Backup e restauração** para levar para outro aparelho.

Abra `index.html` no Chrome, Edge ou Safari, ou use a versão publicada no GitHub Pages.
